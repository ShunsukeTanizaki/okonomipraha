Environment

```
yarn version: 1.22.22
(npm  version: 10.9.2)
node version: v22.14.0
Gatsby CLI version: 5.14.0
```

Set Up

```shell
git clone git@github.com:ShunsukeTanizaki/okonomipraha.git
```

```shell
cd okonomipraha

yarn
```

ローカル開発

```shell
gatusby develop
```

`localhost:8000`

ビルド

```shell
gatusby build
```
